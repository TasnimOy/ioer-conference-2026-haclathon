# Privacy Notice (HaCLAthon Collaboration)

To enable collaborative editing via the browser-based CMS, we process specific data under the following conditions:

1. **Data Processing:** When you log in via the CMS, a temporary GitHub OAuth token is generated. This token is passed through our self-hosted authentication broker at cms-auth.fdz.ioer.info.
2. **Purpose:** The token is used exclusively to permit the CMS to commit your suggested changes to our GitHub repository on your behalf.
3. **Storage:** No personal data is stored on our authentication broker. The OAuth token is stored only in your browser's local storage and is invalidated when you log out.
4. **Git History:** Please be aware that by contributing, your GitHub username will be permanently associated with your changes in the public Git history, which is essential for scientific provenance and author attribution.
5. **Legal Basis:** The processing is based on your explicit consent (Art. 6 (1) (a) DSGVO) given when you initiate the login.
